## Overview

Hotline UGC provides a comprehensive platform for briefing creators, managing video production, and tracking performance directly tied to Meta Ads revenue. You gain full visibility into ROAS, spend, and royalties, enabling data-driven decisions for your campaigns. Key capabilities include real-time dashboard analytics, streamlined creator workflows, video approval processes, and insights into top-performing creatives.

Integrate webhooks to automatically track revenue from Meta Ads.

<CodeGroup tabs="JavaScript,Python">
  ```javascript
  // Webhook handler for revenue events
  app.post('/webhook/revenue', (req, res) => {
    const { campaignId, revenue, adId } = req.body;
    // Sync with Hotline UGC API
    fetch('https://api.hotlineugc.com/v1/campaigns/' + campaignId + '/revenue', {
      method: 'POST',
      headers: { 'Authorization': 'Bearer YOUR_API_KEY' },
      body: JSON.stringify({ revenue, adId })
    });
    res.status(200).send('OK');
  });
  ```
  ```python
  # Webhook handler using Flask
  from flask import Flask, request
  import requests

  app = Flask(__name__)

  @app.route('/webhook/revenue', methods=['POST'])
  def webhook():
      data = request.json
      campaign_id = data['campaignId']
      revenue = data['revenue']
      ad_id = data['adId']
      # Sync with Hotline UGC
      requests.post(
          f'https://api.hotlineugc.com/v1/campaigns/{campaign_id}/revenue',
          headers={'Authorization': 'Bearer YOUR_API_KEY'},
          json={'revenue': revenue, 'ad_id': ad_id}
      )
      return 'OK', 200
  ```
</CodeGroup>
