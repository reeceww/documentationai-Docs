## Recent Updates

Stay informed about the latest improvements to Hotline UGC. You receive notifications for major releases directly in your dashboard under Settings > Updates.

<Callout kind="info">
  Check the [Hotline UGC dashboard](https://dashboard.example.com/settings/updates) for release notes tailored to your account.
</Callout>

<Update label="2024-12-05" description="v1.3.0" tags={["feature", "improvement"]}>

## New Features

- Added real-time ROAS tracking for live ads, showing iROAS updates every 5 minutes.
- Introduced payout caps per creative, helping you control royalties based on performance thresholds.
- New analytics filters for top-performing creators by hook rate, CTR, and NC CPA.

## Improvements

- Enhanced Meta Ads integration for faster video uploads and variant management.
- Dashboard now supports aggregated and individual creative views with customizable metrics.

## Bug Fixes

- Fixed spend tracking discrepancies in multi-currency accounts (A$, USD).
- Resolved payout calculation errors when ads transition from Live to Paused status.

</Update>

<Update label="2024-11-20" description="v1.2.0" tags={["feature", "bugfix"]}>

## New Features

- Creator briefing workflow with templates for hooks, routines, and product audits.
- Integrated Stripe for automated royalty payouts based on conversion value.
- Top Performing Creatives board with performance heatmaps (ROAS, hook rate).

## Bug Fixes

- Corrected NC CPA calculations for videos with low purchase volumes.
- Fixed dashboard refresh issues during high-volume ad tracking.

## Improvements

- Optimized analytics load times by 40% for accounts with 50+ active ads.

</Update>

<Update label="2024-10-15" description="v1.1.0" tags={["feature", "breaking"]}>

## New Features

- Full Meta Ads pipeline: brief creators, ship videos, track spend/revenue.
- Royalties dashboard showing total generated vs. paid, with creator breakdowns.
- Shopify integration for direct product feeds in briefs.

## Breaking Changes

- Updated API endpoints for ad metrics; migrate to `/v2/metrics` for ROAS data.
- Payout logic now requires explicit cap settings (defaults to uncapped).

## Bug Fixes

- Patched webhook failures for Klaviyo event syncing.

</Update>
