---
title: Media Upload Fails
description: Quickly fix failed media uploads in Hotline UGC.
---

## Symptoms

- Upload stalls or shows error message
- File doesn't appear in your library

## Common causes
- File exceeds 200MB
- Unsupported format
- Temporary connection issue

## Quick Fix
<Steps>
  <Step title="Check file type and size">
    Ensure your file is .jpg, .png, .mp4, or .mov and under 200MB.
  </Step>
  <Step title="Retry with stable connection">
    Try uploading again with a reliable internet connection.
  </Step>
  <Step title="Clear browser cache">
    Sometimes browser cache blocks uploads. Clear cache and retry.
  </Step>
</Steps>
